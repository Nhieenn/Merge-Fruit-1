# 🍉 Merge Fruit 3D

Một tựa game giải trí (Casual Puzzle Game) góc nhìn 3D được lấy cảm hứng từ lối chơi ghép trái cây kinh điển. Game đòi hỏi người chơi tính toán không gian, chiến thuật thả quả để tạo ra những chuỗi gộp liên hoàn đầy thỏa mãn!

## ✨ Tính năng nổi bật
* **Core Gameplay:** Cơ chế thả trái cây vật lý 3D mượt mà với đường quỹ đạo ngắm chuẩn xác.
* **Hệ thống Gộp quả (Merge System):** Thuật toán xử lý va chạm chính xác, chống lỗi "gộp kép" và tự động nâng cấp trái cây.
* **Giao diện Glassmorphism:** UI Toolkit hiện đại với phong cách kính mờ trong suốt, kết hợp chữ 3D viền nổi sang trọng.
* **Real-time High Score:** Hệ thống Kỷ lục được lưu trữ và cập nhật trực tiếp theo thời gian thực (PlayerPrefs), kèm hiệu ứng âm thanh và hình ảnh bùng nổ khi phá kỷ lục.
* **Audio Manager:** Phân luồng độc lập giữa Nhạc nền (BGM) và Âm thanh tương tác (SFX), cho phép người chơi tùy chỉnh trong bảng Settings.

## 🎮 Cách điều khiển
* **Di chuyển chuột:** Điều hướng vị trí thả trái cây.
* **Click chuột trái (LMB):** Thả trái cây rơi xuống hộp.
* **Phím ESC:** Bật/Tắt Menu Cài đặt (Settings) nhanh.

## 🛠️ Công nghệ sử dụng
* **Engine:** Unity 3D
* **Ngôn ngữ:** C#
* **Giao diện:** UI Toolkit (UXML/USS)
